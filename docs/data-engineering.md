# 数据工程说明:候选池 → 蒸馏合成 → 清洗配比 → RL 定向池 → 奖励对齐

**简体中文** | [English](data-engineering_en.md)

> 赛题规定:**赛事方不提供训练数据,数据由选手自备,数据策略是核心竞争维度之一**。本文档完整说明本方案的数据来源、合成方法、清洗与验真流程、配比决策、RL 数据定向浓缩,以及后训练阶段奖励与官方评测口径的对齐方式。全部数字与 [决赛技术方案](finals-technical-report.md) 一致。

---

## 0. 总览:三级数据漏斗

```
113,164 候选图          113,159 蒸馏样本          24,251 SFT 精选          1,709 RL 定向池
(第一轮 4 个公开数据集) ──►  (Qwen3.6-27B 教师合成)  ──►  (清洗+验真+配比)  ──►  (RAVEN 单维浓缩)
                          完成度 99.996%            丢弃率 0.524%            奖励信号覆盖 100%
                                                     ▲                        ▲
                                              SFT 宽度优先                RL 深度优先
                                              (初赛 41.8)                (决赛 20.2)
```

每一级的压缩比都服务于一个明确目标:第一级合成解决**数据从无到有**,第二级精选解决**质量与配比**,第三级浓缩解决**RL 信号纯度**。注:24,251 = 第一轮精选 17,924 + round2 定向补蒸 6,327(round2 图源为另外 4 个公开数据集,见 §1.1);RL 池独立取自 RAVEN。

## 1. 候选图像池(数据来源)

赛事方不提供训练数据 ⇒ 全部训练数据自行构建。候选池来自 4 个公开多模态数据集,共 **113,164 张图**:

| 数据集 | 性质 | 对应考察方向 |
| --- | --- | --- |
| CLEVR-Math | 合成场景几何计数与数值推理 | 计数 / 数值计算 |
| ChartQA | 图表问答 | 数值计算(表格/账单类) |
| ScienceQA | 科学知识多模态问答 | 物理常识 |
| VSR | 视觉空间关系判断 | 空间推理 / 细粒度感知 |

选池原则:对准初赛六大考察维度(数值计算、计数、空间推理、物理常识、细粒度视觉感知、图文联想),以公开数据集为底座、教师模型合成标注——规避人工标注的成本与规模瓶颈。四个底座均为公开学术基准:ChartQA(ACL 2021)、ScienceQA(NeurIPS 2022)、VSR(TACL 2022)、CLEVR-Math(CLEVR 衍生的合成数学推理集)。

### 1.1 round2 定向补蒸的追加来源(另外 4 个公开数据集)

train_v4 并非全部来自第一轮候选池:在 v2 旧精选 17,924 条之外,round2 针对四个方向补充蒸馏约 6,327 条(经教师答案与参考答案判等验真后并入,见 §3.2),其图源是**另外四个公开数据集**:

| 数据集 | 性质 | 补充方向(六维 pool) |
| --- | --- | --- |
| GQA(CVPR 2019) | 场景图问答 | spatial |
| PlotQA(WACV 2020) | 图表数值问答 | numeric |
| FSC-147(NeurIPS 2021) | 开放世界目标计数 | counting |
| PhyX | 物理常识图文 | physics |

> 证据:[sft/scripts/merge_train_v4.py](../sft/scripts/merge_train_v4.py) 的 `POOL_MAP` 按 round2 样本的 `source` 字段将新数据归入上述四池(决赛技术方案未展开这一层来源)。两轮合计 **8 个公开数据集,全程无私有数据源**。

## 2. 教师蒸馏合成(怎么合成)

| 项 | 值 |
| --- | --- |
| 教师模型 | Qwen3.6-27B,本地 vLLM 推理(bf16,TP=2) |
| 批处理 | 每批 64 图、并发 16,吞吐 ~0.85 条/s |
| 产出 | **113,159 条** LLaVA 风格样本(完成度 99.996%) |
| 格式 | 单轮对话:`<image>` + 中文提示 + `\boxed{}` 答案——与官方评测提取格式同构(官方要求"最终答案放在 \boxed{} 中",否则评测无法识别) |
| 可靠性 | 54 小时无人值守,**35 次 NPU ERR99999 崩溃全部自愈**(三层看护:主循环重试 + 30min keepalive + 外部监督进程),有效吞吐 75% |

合成产出的类别分布(按考察维度标注):

| 维度 | 样本数 | 占比 |
| --- | ---: | ---: |
| spatial | 44,231 | 39.1% |
| numeric | 28,731 | 25.4% |
| counting | 27,203 | 24.0% |
| perception | 12,376 | 10.9% |
| physics | 618 | **0.5%** |

**physics 天然稀缺是这一步的关键发现**:公开数据池里物理常识素材极少,直接埋下了后续"弱维画像 → RL 选维"决策链的伏笔(见 §5)。

## 3. 清洗与验真(怎么洗)

三级漏斗的第二级:113,159 → 24,251,**总丢弃率仅 0.524%**。清洗不是大幅砍数据,而是"验真 + 过滤 + 合并"三件事:

### 3.1 硬过滤

- **超大图过滤**:127 条超大图被过滤;**too_long = 0**(没有样本因超长被丢弃)。
- **token 长度审计**:p50 = 325 / p90 = 1156 / max = 2041,对 max_len = 2048 全量通过——即没有为迁就截断而损失任何样本,长度分布留足了推理展开空间。

### 3.2 round2 验真并入

train_v4 的构成是**两批数据的验真合并**:

```
train_v4 (24,251) = train_v2 旧数据 (17,924) + round2 新蒸馏·验真后并入 (~6,327)
```

round2 针对 spatial / physics / numeric / counting 四个方向补充蒸馏(图源 GQA / PlotQA / PhyX / FSC-147,见 §1.1),新产出先经验真(教师答案与参考答案判等校验)再并入,避免蒸馏噪声直接进训练。合并逻辑见 [sft/scripts/merge_train_v4.py](../sft/scripts/merge_train_v4.py)(图片路径支持相对 + 绝对双形式,训练前全量回读校验)。

### 3.3 最终配比(train_v4)

| 类别 | 占比 | 对应决赛考察方向(按任务性质归纳) |
| --- | ---: | --- |
| 专业领域推理 | 43.6% | 专业领域推理(化学/数学) |
| 代码与时空推演 | 34.3% | 代码解读与时空推演 |
| perception | 14.8% | 细粒度视觉感知 / OCR 文字提取 |
| 抽象图形 | 7.25% | 抽象图形规律(九宫格 IQ 测试) |

头部两类恰好覆盖决赛官方考察维度的前两维;抽象图形虽只占 7.25%,但为决赛 RL 阶段保留了这个方向的底子(见 §5——这正是最终 RL 增益的来源)。

注:本表构成百分比按**决赛四维考察方向**对同一批训练数据做任务性质归纳,与 §2 的六维标注是同一数据的两种统计口径;两轮蒸馏候选池始终限于 §1 的公开数据集,round2 也未引入私有来源。

### 3.4 配比实验方法论

v3 → v4 的演进是**变量隔离实验**:配置完全相同(2 epoch / LoRA r16 α32 / lr 1e-4 / eff_bs 16),仅数据规模扩大(v2 → v4)。结论:配置侧收益(+3.4)吃满后,杠杆转移到数据侧(+0.4)。——数据配比的收益必须用"只动数据"的对照来证明,而不是与配置调优混在一起。

## 4. RL 数据定向浓缩(1,709 条)

第三级漏斗:不追求覆盖,追求**分布匹配 + 奖励信号纯度**。

### 4.1 池子构建

`rl3_data_abs.jsonl`:**RAVEN 九宫格抽象推理 1,709 条**(RAVEN,Zhang et al., CVPR 2019,公开抽象推理数据集)——前 8 格规律推第 9 格,8 选 1,答案为编号 1–8(`\boxed{5}` 形式)。

质量审计四项全过:

| 审计项 | 结果 |
| --- | --- |
| boxed 可抽取率 | 100% |
| 奖励信号覆盖(答案可精确匹配) | 100% |
| 图片重复 | 0 |
| 图片路径回读 | 全量绝对路径校验通过 |

### 4.2 为什么是 abstract 单维(选维决策链)

1. **弱维画像打底**:v4 底座、每 prompt 8 采样的六维画像显示 association 0.212 为第二弱维,且该题型奖励信号 100% 可覆盖;
2. **physics 更弱但不可用**:0.079 更弱,但合成 physics 数据与评测分布不匹配,实测无迁移(ph1 实验 18.8,噪声带内);
3. **官方维度印证**:决赛赛题将「抽象图形规律:矩阵图形的复合规律发现与逻辑推理,例如经典九宫格 IQ 测试」列为四大核心考察维度之一——池选择与官方考察方向直接对齐;
4. **消融裁决**:abstract 单维 20.2 > physics 单维 18.8 > 六维均衡 17.8 > 六维补全 16.8 > counting 单维 16.4。**池与隐藏评测集的分布匹配度是决定因素,不是覆盖面**。

## 5. 后训练对齐(奖励 = 评测口径)

赛题的评测提取规则由官方代码规定(`rfind` 定位 `\boxed{` / `boxed{` 前缀,大括号深度计数支持任意嵌套)。本方案的奖励函数**与官方提取器逐字一致**:

```
R = acc + 0.5 × fmt  (结构上等效于三档离散奖励)
  ├─ 抽出 \boxed{} 且归一化后与参考答案相等 → 1.0
  ├─ 抽出 \boxed{} 但答案错误               → 0.05(格式地板,保住格式梯度)
  └─ 抽不出 \boxed{}                        → 0.0
```

| 对齐项 | 实现 |
| --- | --- |
| 答案提取 | 与官方 `extract_boxed_answer` 同算法:`rfind` + 括号深度计数,任意嵌套 100% 支持 |
| 答案归一化 | 去空白 / 去标点 / 全半角折叠 + lower,与平台判分完全同口径 |
| 结论 | **训练奖励即评测目标,无 reward hacking 空间**——模型刷高奖励的唯一途径是答对题 |

配套的稳健性设计:

- **答案类型感知**:bool / choice / num / text 四分类 + "参考答案自洽率"审计(任一类型 < 100% 即该类型白训);
- **零梯度防护**:监控 `frac_reward_zero_std`(组内奖励全同 → 梯度为 0 的步占比),防止无效步累积;
- **格式地板 0.05**:错误但格式正确的答案保留微小梯度,避免格式学习信号消失。
